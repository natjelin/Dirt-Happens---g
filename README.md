# Dirt Happens

A small website for sharing trail running routes: an interactive map, search and filters (distance, climb, tags), an elevation profile per route, and a GPX download button. The whole site is static files generated by one Python script, so it can be hosted for free on GitHub Pages.

Python 3.9 or newer. There is nothing to install.

## Try it

```bash
python build_map.py --routes sample_routes --serve
```

Open http://127.0.0.1:8000. The sample routes are made-up data. The map tiles load from the internet.

## Use your own routes

1. Put your GPX files in `routes/`. Strava, Garmin, Coros, Komoot and Suunto can all export GPX.
2. Run `python build_map.py --serve`.

Everything is read from the files: distance, climb, descent, high and low point, date, and whether the route is a loop, an out-and-back or point-to-point. Nothing else to fill in.

### Optional details for a route

Add a JSON file with the same name next to the GPX. Everything in it is optional:

```json
{
  "name": "Lac Blanc out and back",
  "description": "Rocky final kilometre, worth it for the lake.",
  "tags": ["technical", "views"],
  "author": "Ben"
}
```

Tags become filter buttons on the site. Without `author`, the name of the folder the file is in is used (`routes/ben/lake.gpx` is shown as added by "ben").

### Settings

`config.json` holds the site title, tagline, the privacy trim (below) and `repo_url`. Once the repository exists, put its address in `repo_url` (for example `https://github.com/you/dirt-happens`) and the site shows an "Add a route" link.

## Put it on GitHub

1. Create a new repository on GitHub and push this folder to it (the default branch should be `main`).
2. In the repository go to **Settings → Pages** and set **Source** to **GitHub Actions**.
3. Every push to `main` rebuilds the site and publishes it at `https://<your-username>.github.io/<repository>/`.

## Add a route

(The site's "Add a route" link points here.)

**You:** copy the GPX file into `routes/`, commit and push.

**Friends with a GitHub account:**
1. Fork the repository.
2. Add your GPX file as `routes/<your-name>/<route>.gpx`. An optional `<route>.json` next to it adds a description and tags.
3. Open a pull request.

A check runs on every pull request and fails if the file is not a usable GPX. The route only goes live when you merge it. Close the pull request to say no.

You can also add friends as collaborators so they can commit to `routes/` directly.

## Privacy and access: read this before publishing

**Anyone with the link can view the site.** GitHub Pages sites are public on the free plan, and the repository has to be public too. Restricting who can *view* a Pages site needs a paid GitHub Enterprise Cloud plan. You do control who can *add* routes: nothing is published until you merge it.

What the build does to protect you:

- It cuts the first and last 200 m off every published track (change it with `privacy_trim_m` in `config.json`, or `--trim`), so a start next to your front door is not on the map or in the download.
- It removes timestamps, heart rate and other sensor data from the GPX files people download.

What it cannot do: **the original files in `routes/` are visible to everyone if the repository is public.** If a route starts or ends at your home, trim it yourself in a GPX editor before committing it, or leave that route out. The distance and climb on the site are those of the full route.

## How it works

`build_map.py` reads every `.gpx` under `routes/`, validates it, computes the statistics, and writes `site/index.html` plus one cleaned GPX per route in `site/gpx/`. The page uses [Leaflet](https://leafletjs.com) with OpenTopoMap and OpenStreetMap tiles. Route names and descriptions are only ever inserted as text, never as HTML, so a contributed file cannot inject code into the page.

| File | Purpose |
| --- | --- |
| `build_map.py` | the whole pipeline |
| `template.html` | the page: map, filters, elevation profile |
| `config.json` | title, tagline, privacy trim, repository address |
| `routes/` | your GPX files |
| `sample_routes/` | made-up routes for trying things out |
| `.github/workflows/pages.yml` | builds, checks pull requests and publishes |

## Command line

```
python build_map.py                 build site/ from routes/
python build_map.py --serve         build, then preview on http://127.0.0.1:8000
python build_map.py --strict        fail if any route file is invalid (used by the pull request check)
python build_map.py --trim 300      override the privacy trim, in metres
python build_map.py --routes DIR    read GPX files from another folder
```
